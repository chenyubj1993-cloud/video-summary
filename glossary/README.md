# 术语表（glossary）

转写错误里真正能靠"表"解决的部分，都在这里。它是这个项目里**唯一会随使用变聪明的资产**：
模型换一版就作废，词表不会。

## 三层结构

| 层 | 文件 | 规模 | 维护频率 | 解决什么 |
|---|---|---|---|---|
| L0 通用领域词 | `common.tsv`、`ai.tsv`、`cv.tsv`… | 每表 50–500 条 | 一次维护，长期复用 | 「任务→论物」这类跨视频的高频错听 |
| L1 系列专名 | `series/<BV号>.tsv` | 每系列 20–50 条 | 每接一个新系列 10 分钟 | 模型没见过的专名（DINO→Deno、LLaVA→Lava） |
| L2 自动发现 | 不进文件，运行期产出 | — | 全自动 | 从低频重复 n-gram + 低置信句反推候选，人工确认后升进 L0/L1 |

## 文件格式

UTF-8、Tab 分隔、四列，`#` 开头为注释：

```
规范词 <TAB> 误听形（多个用 | 分隔） <TAB> 上下文约束（前_后，留空=全文生效） <TAB> 状态
```

```
任务	论物|论武|论五		obs
任务	论文	下游_|前置_	obs
预训练	预训链|预讯链		obs
DINO	Deno|deno		obs
LLaVA	拉瓦|Lava		hyp
```

- **状态 `obs`**：本机实测观测到的错误，`vsummary/fix.py` 会真的改。
- **状态 `hyp`**：推测的谐音候选，只做命中统计、**不改文本**——防止凭空污染。
- **上下文约束**：`下游_|前置_` 表示只有前面是「下游」或「前置」时才替换。用于「论文」这类
  本身合法的词：单独出现时是"论文"，跟在"下游"后面才是被听错的"任务"。

## 三条硬规矩

1. **只存"误听形"，不存正确写法。** 替换是 `误听形 → 规范词` 单向的；反过来的表会让正常文本
   被改坏（例如把每处"线性探测"改成"Linear Probing"）。
2. **不做跨语言替换、不吞实义词。** 「Linear Probing → 线性探测」「Flamingo模型 → Flamingo」
   这类规则一律拒绝，它们属于改写，不属于纠错。
3. **合法词不进表。** 「论文」「任务」「模型」本身都是合法中文，只能用搭配约束（前者必须紧跟
   「下游/前置」）或干脆不收。原本指望 `avg_logprob < -0.6` 兜底，但**实测失效**：10,800 句里
   最小只有 -0.266，一句都没触发——VAD 已切掉噪声，模型对剩下的句子都很自信，而"自信≠正确"。

## 当前状态（BV1E9U8BBEvZ）

47 条生效规则，在 40 个分P 上命中 **273 处**。第二批 34 条是拿讲义「存疑与勘误」的 44 条回填的，
每条都核对过上下文才升 `obs`。刻意没收的：`VQ`（可能指 VQ-VAE）、`Bot`（chatbot）、
`论文`（合法词）、`2400`（端口号需回听音频），它们留在 `hyp` 或根本不进表。

## 用法

```bat
python cli.py classify BV1E9U8BBEvZ    :: 先判行业（多标签 + 置信比）
python cli.py fix BV1E9U8BBEvZ --emit  :: 再纠错，产出 changes.md 可逐条复核
```

行业判定为**多标签**，且在 `out/<bv>/domain.json` 留痕（`confidence` 低于 1.2 会标
`needs_llm_check`）。行业只决定"加载哪几张表"，判错的代价是"多加载了一张没用的表"，
而不是"把对的字改错"。

## 冷启动：不让人从零想

```bat
python cli.py coldstart BV1E9U8BBEvZ          :: 扫原始转写，提候选（全部 hyp）
python cli.py coldstart BV1E9U8BBEvZ --eval   :: 拿现有 obs 规则当答案，量一下召回
```

原理是拿 `glossary/terms/ai.tsv` 里的专名词典做编辑距离匹配，把 `PanelGPT / vikuna /
lessnets50 / PyTouch / gigsaw / embeding` 这类"拼写漂移"提出来。加了四道过滤挡噪声：
常见英文词、包含关系（`adapt` vs `Adapter`）、短词低相似度、四字母词要重复出现。

实测（BV1E9U8BBEvZ，4452 个英数串 → 58 条候选）：**英文专名类找回约 24%**，
候选多数是对的（`PanelGPT→PandaGPT`、`vikuna→Vicuna`、`lessnets50→ResNet50`）。
**中文同音错（拉玛→LLaMA）和纯数字错（718→768）这个方法不处理**——前者要拼音/听感，
后者要回听音频。别指望它替你干完，它是把"从零想"变成"过一遍"。



术语密度高 × 视频长 × 有专业用途。目前只有 AI/CV/编程；医学、法律、金融值得。
美食、旅游、游戏不值得——术语太散，建表收益低于人工看一下。
